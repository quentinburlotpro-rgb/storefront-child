# Storefront Child — Amorino Click & Collect

Thème enfant de Storefront — SAé 3.01, BUT MMI, IUT du Limousin.

- `inc/itNN-*.php` : code de chaque itération (chargé automatiquement)
- `assets/css/` : styles, dans l’ordre de la cascade
- surcharges de templates : `header.php`, `footer.php`, `template-homepage.php`, `woocommerce/`, `archive-membre.php`, `single-membre.php`
- `acf-json/` : groupes de champs Secure Custom Fields (Local JSON)
- `setup/` : scripts WP-CLI qui créent les contenus de chaque itération
